## 5. Scientific Scope and Non-Negotiable Decisions

### Selected strategy

Use the conservative combined library strategy:

```text
DED/TIGRFAM family definitions
  -> manually curated, experimentally supported sequence seeds
  -> MAFFT + hmmbuild custom family profiles
  -> HMMER scan of complete new GTDB proteomes
  -> InterPro/domain-architecture and localization review
  -> family gene trees plus GTDB taxonomy/species-tree analysis
```

This is a new analysis. Do **not** compare results to the prior project, do **not** overwrite the prior project, and do **not** label anything `v4`. Use the independent stage names `P01`, `P02`, ..., `P10` and the existing numbered directory layout.

### Interpretation boundary

A sequence hit supports a stated level of homology/domain evidence; it does not prove PHB degradation in vivo. Report experimental activity evidence separately from HMM, domain, localization, and phylogenetic evidence.

### Required family separation

Keep these categories distinct in the reference manifest, profiles, candidate table, and trees:

1. Intracellular PhaZ lacking the classic lipase-box motif; include `TIGR01849`.
2. Extracellular scl-PHA depolymerase Type I.
3. Extracellular scl-PHA depolymerase Type II.
4. PhaZ7-like proteins.
5. PhaZd-like proteins.
6. *Rhodospirillum* periplasmic-like proteins.
7. Intracellular mcl-PHA depolymerases.
8. Extracellular mcl-PHA depolymerases.
9. `TIGR02240`/aromatic-PHA-related route, separately labeled.
10. Auxiliary mobilization/context genes, explicitly marked as context rather than core depolymerases.

The DED framework describes eight PHA-depolymerase superfamilies and 38 homologous families. The legacy DED site was not reliably retrievable during prior work; rebuild an auditable library from accessioned literature seeds instead of assuming downloadable DED HMMs exist.

`TIGR01849` has HMM length 406 and trusted cutoff 300.75. It is important because a mandatory `GXSXG` motif filter would incorrectly exclude this intracellular PhaZ route. Use the TIGRFAM trusted cutoff for the released model. Calibrate custom HMMs separately with positive seeds and close negative controls.
