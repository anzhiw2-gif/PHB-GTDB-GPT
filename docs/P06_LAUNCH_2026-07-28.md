## Smoke And Recovery Evidence

One accepted P03 proteome completed all four HMMER jobs with exit code 0 and parsed with no missing raw output. A second four-model synthetic smoke containing a normal protein plus a 100,001-aa protein also completed: each model recorded that overlong target as `hmmsearch_target_length_gt_100000`, without an HMMER abort.

HMMER 3.4 cannot process individual targets longer than 100,000 aa with the standard comparison pipeline. `scripts/p06_stream_proteomes.py` streams eligible proteins to HMMER and records overlong records in ignored `overlong_protein_exclusions/<family>/<chunk>.tsv` tables with source path, target identifier, length, and tool-limit reason. These records are not HMMER negatives.

`scripts/p06_run_family_profiles.py` writes atomic status checkpoints. It skips only a nonempty `domtblout` whose family/shard/path key is already marked `completed` or `skipped_existing`; an uncheckpointed nonempty file after interruption is rerun. Raw outputs and live checkpoint tables remain outside Git. Candidate parsing and reporting wait until there are no failed jobs. HMM hits remain sequence evidence, not proof of a PHB/PHA-degradation phenotype.
